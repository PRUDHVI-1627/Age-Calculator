# ✦ Age Calculator

A warm, beautifully designed age calculator that tells you exactly how old you are — down to years, months, days, total hours, and even minutes lived.

---

## What it does

- Calculates your exact age in **years, months, and days**
- Shows fun stats: total days, hours, and minutes you've been alive
- Counts down **days until your next birthday**
- Displays a personalised message based on your age
- Celebrates 🎂 if today happens to be your birthday
- Fully validates your input with friendly error messages

## How to run

No build tools, no dependencies, no npm install. Just open it.

```bash
# Option 1 — double-click
Open index.html in any modern browser.

# Option 2 — local server (optional, for development)
npx serve .
# or
python3 -m http.server 8080
```

## Design

**Palette:** Warm cream + peach + sage green + blush pink — soft and feel-good without being clinical.

**Typography:**
- *Playfair Display* (serif) — for headings and numbers, gives it a warm editorial feel
- *DM Sans* — clean, friendly, lightweight for body text and labels

**Effects:**
- Soft animated background blobs that slowly drift
- Frosted glass card with backdrop blur
- Counting animation on the result numbers
- Smooth slide-up reveal of results
- Hover lift on result cards
- Button shimmer on hover

---

## Browser support

Works in all modern browsers: Chrome, Firefox, Safari, Edge.  
No polyfills needed. Pure HTML + CSS + Vanilla JS.
